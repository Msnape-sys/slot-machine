# The Appointment

The Appointment is a slot machine project that I turned into a beauty appointment game. Instead of using a traditional casino theme, I wanted to make the project more creative and build something that felt more like my own.

Live Site: https://myjah-slot-machine.netlify.app/

## About the Project

This project originally started as a JavaScript assignment to build a working slot machine. The requirements included having at least five possible items on each reel, allowing the user to place a bet, and updating their balance based on the results.

I decided to take the basic idea and give it a beauty theme.

In The Appointment, the player starts with a $1,000 Beauty Budget and can choose different beauty services. The game then generates a random result and determines whether the player wins a Beauty Bonus.

The main goal for me was to get the JavaScript working correctly while also making the project feel more like something I would actually want to build.

## How It Works

The player starts with a $1,000 Beauty Budget.

They choose a beauty service and book their appointment. Once they play, JavaScript randomly generates the slot results and checks for a winning combination.

The page then updates based on what happened, including the player's remaining budget and any Beauty Bonus they earned.
